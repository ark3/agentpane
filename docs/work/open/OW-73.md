# Typing `/compact` in the composer silently sends it to the model as literal text.

Observed live against Codex (owner, 2026-08-18): the model received the string
and answered it, and nothing said it would. Nothing in the stack inspects the
draft — `App.svelte:550` `submitPrompt` → `controller.ts:259` `submit` →
`api.prompt` → `adapter.submit(text)` — and a grep for slash handling across
`src/` finds none at all. Pi behaves identically; this is not a Codex quirk.

**This item adds no commands.** The fix is a UI-side warning and nothing else,
decided by the owner this session, who did not want real commands wired into the
composer. When the draft is exactly one of a small known list — `/compact`,
`/clear`, `/new` — do not send it, and show a message saying Agentpane does not
run slash commands, naming what to do instead. **Only an exact bare match**:
`/compact the last hour` is a prompt and must still send untouched.

Two of the three have no Agentpane equivalent, so what each points at differs.
`/compact` → the tools menu (OW-72). `/new` → the New button in the session
controls (`App.svelte:603`). `/clear` → nothing exists, so say so; starting a
new session is the nearest thing. Getting this list exactly right matters much
less than never silently sending — OW-74 is where the surface as a whole gets
decided, and these three are a stopgap sized to what the owner has typed by
mistake.

Ordering against OW-72: if this lands first there is no tools menu to name, so
either land it after, or word the `/compact` case for the world where the menu
does not exist and revisit it when OW-72 lands.

## Done when

A client test sets the draft to `/compact`, submits, and asserts `api.prompt`
