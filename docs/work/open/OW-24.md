# No browser E2E covers a real backend-backed turn.

whole client; `playwright.config.ts`, `e2e/`, a real-turn browser path through the Bun server

The repo now has one Playwright vehicle — `package.json`'s `bun run
test:browser` — but `playwright.config.ts` calls it exactly what it is: *"One
browser test vehicle, for follow mode"*. It serves `e2e/harness.html` through
Vite and drives the real `App.svelte` plus the real `controller.ts` against a
synthetic `AgentpaneApi` port (`e2e/harness.ts`), with no backend and no
subprocess. So the old all-jsdom claim is no longer true: follow mode, scroll
anchoring, `ResizeObserver`, and real scroll-event timing are now pinned in
Chromium, and OW-47 is closed on that basis. What remains unverified is the
**end-to-end browser path** DESIGN names (`docs/DESIGN.md:632-639`): transcript
rendering, tool cards, preview/attach flows, rename handling, and any other
client `$effect` as they behave when the page is served by the production server
and a real or scripted backend turn streams over REST/SSE. OW-41
(`docs/work/closed/OW-41.md`) is still the proof of why that matters: 605 green
jsdom tests missed a startup infinite loop because `FakeController` diverged
from the real controller, and OW-42 tracks the part of that divergence still
open. Grounding for the executor: the production server already binds 127.0.0.1
and honors `PORT` (`src/server/index.ts`, default 4173); the SPA fallback on `/`
requires an `Accept: text/html` navigation header (`src/server/http/static.ts`,
reproduced in `docs/MANUAL_TESTING.md`); and any real-turn spec should mirror
the smoke harnesses (`resources/probes/agentpane_{codex,pi}_smoke.py`) by
asserting on structure, never model wording. The browser suite must stay outside
`bun run check` unless OW-49 is settled at the same time. Done when: a
Playwright spec builds and serves the app through the real server, drives a
browser path beyond the synthetic follow harness — either against a live backend
turn or a scripted/mock-LLM — and structurally asserts the streamed
transcript/tool surfaces with closing evidence in `docs/MANUAL_TESTING.md`.
