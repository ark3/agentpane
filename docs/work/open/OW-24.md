# No Playwright path crosses the production HTTP/SSE server into the real controller and transcript.

`playwright.config.ts`; `e2e/harness.ts`; `src/server/index.ts`; `src/server/composition.ts`; `src/server/http/app.ts`; `src/server/http/session-manager.ts`; `src/client/api.ts`; `src/client/controller.ts`; `docs/DESIGN.md`, "Testing strategy".

The browser situation has changed since this card was first written: `bunx playwright test --list` on 2026-08-28 reports eight tests across seven spec files, covering follow mode, the navigation rail, Popover dismissal, composer and footer geometry, edit/fork chrome, and favicon wiring.
That is now a useful deterministic browser UI suite, not merely OW-47's one-defect vehicle, and this card must not replace or duplicate it.
What remains absent is the one boundary DESIGN still names: a built SPA served by the production Bun server, using the real REST and SSE client, real controller, and real transcript against a deterministic scripted backend.

## The one vertical slice

Add one Playwright scenario that starts the production server with a scripted `BackendAdapter` supplied through the existing composition seams, never a live Pi, Codex, or Claude CLI.
The script should give the page a stored session to preview, allow it to attach, accept one prompt, and emit a structurally fixed turn containing user content, thinking, a tool call, its correlated result, and final assistant prose over the production routes and multiplexed SSE stream.
The assertion is on DOM and message structure, never scripted or model wording: the preview appears without a spawn, attach exposes the composer, the submitted turn reaches the transcript, and the thinking/tool/result/final surfaces arrive in order.
A rename, fork, error path, backend matrix, screenshot matrix, and live-model call are outside this first slice; existing unit, contract, and synthetic-browser tests keep those jobs until a concrete integration failure earns another card.

Prefer a test-only server entry under `e2e/` over a second production composition, and keep the frozen `BackendAdapter` contract unchanged.
The production server already binds `127.0.0.1` and honors `PORT` in `src/server/index.ts`; the SPA fallback in `src/server/http/static.ts` requires an `Accept: text/html` navigation header; `src/server/http/vertical-slice.test.ts` is the nearest transport-boundary precedent.
