# Nothing pushes, so the two clones only converge when the owner moves commits by hand.

`AGENTS.md`, "Landing work"

`AGENTS.md` says "Never `git push` unless asked by name", written when this was
a single-machine repo that was never pushed. That premise expired on 2026-08-17:
authoring moved to a work laptop and implementation to a home server over Claude
Code remote, with `origin` (`git@github.com:ark3/agentpane.git`) the only path
between them — `main` and `origin/main` were level when this row was written, so
the pushing is happening, just manually. OW-54 removes the *conflicts* between
those clones but not the *latency*, and the two are independent: file
granularity makes the meeting free, push/pull is what makes the branches meet at
all. **Deferred by the owner on 2026-08-17, who called it a "me problem" for
another day** — so do not change the rule and do not push until he says so by
name. Recorded only so the decision is findable and so the `AGENTS.md` rule is
known to rest on a dead premise rather than a live one; a future agent reading
that line should not infer the repo is unpushed. Revisit when the owner raises
it, or if a row is ever lost or duplicated because the clones drifted.
