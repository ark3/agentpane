# Nothing reports a child that outlives SIGKILL.

Codex's `finishTermination` discards the boolean from `closesWithin`, Pi's now
does the same, and the manager swallows dispose rejections — so the one
condition DESIGN worried about is the one condition no layer would tell you
about. Making `kill()` record or throw on a false return is the fix.
