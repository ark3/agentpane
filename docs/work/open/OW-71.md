# A preview shows no real times: `SessionPreviewTurn` drops the timestamp its JSONL record carries, so every message renders as the epoch.

`previewMessages` builds each `AgentMessage` with `timestamp: NO_TIMESTAMP`,
which is `0`, because `SessionPreviewTurn` carries `role` and `text` and nothing
else — the comment there says so outright, and until OW-67 nothing rendered a
message time, so the zero was invisible. It is visible now: every message of
every preview, both backends, reads as the epoch. Observed 2026-08-18.

The data is on disk. A real Codex capture read that day
(`~/.codex/sessions/2026/08/12/rollout-2026-08-12T22-10-29-019ff8e2-….jsonl`)
carries a record-level `"timestamp":"2026-08-13T02:10:54.809Z"` on every
`response_item` line, and both extractors already parse the whole record and
simply drop the field. Pi's per-record `timestamp` is read today at
`src/server/sessions/pi.ts:39` for `createdAt`, so the field exists on Pi
records — but **this machine has no `~/.pi` at all**, so the message-record
shape is unverified against a real capture; confirm it on a machine that has
one before trusting the fixtures.

So: widen `SessionPreviewTurn` with the timestamp, fill it in `extractTextTurn`
on both backends, and convert in `previewMessages`. `AgentMessage.timestamp` is
a required `number`, so something must turn the stored ISO string into epoch-ms
— at the client edge, or on the wire; either is defensible, pick one and say
which in the commit message.

A record with no parsable timestamp must render **nothing**, not the epoch, and
not a clock read — a synthesized time is a lie the reader cannot detect. Carry
it as optional and have the render path skip an absent one. The user declined a
standalone patch that only hid the zero (2026-08-18), on the grounds that real
timestamps make it moot; the hiding is still needed for the genuinely-absent
case, and this item is where it belongs rather than as a change of its own.

Done when a hermetic fixture in `preview.test.ts` — which already builds both
backends' record shapes — proves the extractor carries the record's timestamp
through for pi and for codex; when a client test proves a preview message
renders its real time and that a turn without one renders no time at all; and
when a preview opened by hand shows times agreeing with the session list's own
column for that session. Load-bearing: real times end to end, absent renders
nothing, no clock reads anywhere. Incidental: the wire representation and where
the ISO-to-epoch conversion sits.

Independent of OW-70, in either order: if the local-time switch has landed
first, these times are simply local too, through the same shared formatter.
