# Nobody has decided which commands Agentpane offers, or how each maps onto Pi and Codex.

Raised by the owner on 2026-08-18 after typing `/compact` and watching it go to
the model verbatim. The immediate case is handled twice over — OW-70 puts
compaction behind a tools menu, OW-71 warns about the typed form — but neither
answers the general shape: which operations Agentpane offers beyond sending a
prompt, how a person reaches them, and what each does on a backend that lacks
it.

The owner's stated instinct is **against** wiring real commands into the
composer — "feels wrong", reason not yet articulated. A design that routes typed
`/x` to actions has to address that instinct rather than route around it, and
articulating it is part of settling this item.

The question is live rather than hypothetical because capability is already
piling up server-side with no way to reach it. Three cases exist today, each
with adapter methods and HTTP routes and **zero** client surface: fork
(`listForkPoints`/`fork`, routes at `src/shared/protocol.ts:239` and `:247`),
model selection (`setModel`/`listModels`, `GET /api/models` served at
`src/server/http/app.ts:73`), and image attachment (`submit(text, images?)`).
Every one of them will need the same answer this item owes.

The backends do not offer the same set, which is the hard part. Codex
app-server's request surface — enumerate it with `codex app-server
generate-json-schema --out <dir> --experimental` and read `ClientRequest.json` —
includes `thread/rollback`, `thread/archive`, `thread/search`,
`thread/shellCommand` and `thread/injectItems`, none of which appear in
`PiCommand` (`src/server/adapters/pi/protocol.ts:24`). Pi's surface is not fully
known here either: its header says thinking level, compaction knobs,
bash-as-a-command and session naming are all real commands the adapter never
sends. So the decision has to cover what Agentpane shows for an operation one
backend has and the other does not — hide it, grey it, or say why it is absent.

This item closes when the decision is made, not when anything is built: the
decision goes to `DESIGN.md` as a numbered decision (the `D` series), and
whatever it implies becomes its own items.
