## Close note

Superseded by OW-bulanu (landed 2026-09-29): a startup is retired from `#attaching` in the same synchronous run that publishes its adapter to the table, and a parked handle leaves `#pendingForks` at the claim, so `disposeAll()` reaches each adapter by one route alone.
