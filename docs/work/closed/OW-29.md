# "New session" is enabled with an empty workspace.

`src/client/App.svelte:88`

Read from source, not yet observed.

Came out of the first hand-run of the built client on 2026-08-12, one of the
OW-26–OW-31 group; only OW-26 was observed directly, and this one was read out
of the shell's source in the same session.

**Fixed** in `26d104f` as part of OW-39: `New session` now inherits the selected
session's workspace and is `disabled` whenever there is none to inherit
(`disabled={!newSessionWorkspace}`). Pinned by `App.test.ts` ("disables New
session when there is no selected workspace to inherit"). Note: the flip side of
this — that a workspace with no sessions can no longer be created at all — is
tracked as OW-40.
