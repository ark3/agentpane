naming OW-24, OW-26..OW-31, OW-36, OW-38..OW-47 and OW-49 in prose, with a
clause appended per close (see `9ad0a6d`, "record the four landed rows in the
status table"). That breaks the rule this file and `AGENTS.md` both state — cite
ids, never restate a row — and this cell is where the file previously

while there — they are one line each today, which is the target shape.

closing the next row requires no edit to this cell.
